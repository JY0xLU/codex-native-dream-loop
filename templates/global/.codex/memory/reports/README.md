# reports

Reports are human-readable summaries of Dream Loop maintenance runs.

Use reports to show:

- promoted items
- archived items
- rejected proposals
- unresolved inbox count
- stale `ACTIVE.md` entries
- fixture or gate status
- next smallest useful action

Reports are output artifacts. They should summarize `ACTIVE.md`, `LEARNINGS.md`, `staged/`, `rejected/`, and `AUDIT_LOG.md`, but they are not recall layers.
