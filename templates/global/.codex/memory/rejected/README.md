# rejected

Rejected proposals preserve why a plausible memory change did not land.

Use this directory when a candidate fails the validation gate, lacks enough source evidence, has unclear scope, or loses to a better route.

Each rejected bundle should explain:

- what candidate was rejected
- which gate check failed
- what evidence would be needed to retry
- whether any related route should be archived or left in `inbox/`

Rejected proposals are evidence for future consolidation, not default recall material.
