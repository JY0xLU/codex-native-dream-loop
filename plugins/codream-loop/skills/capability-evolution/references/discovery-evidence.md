# Discovery Evidence Checklist

Use this checklist when capability discovery is non-trivial or when the user questions whether discovery is really working.

Record:

- which enabled official plugin or tool path was checked
- whether an installable official plugin exactly matched the task
- which local skills were considered
- whether GitHub or external search was reached, skipped, or blocked
- the best candidate, rejected candidates, and the concrete reason each lost

Escalate to GitHub or external project search when all of these are true:

- official plugins do not cover the task well enough
- local skills do not cover the task well enough
- the expected gain is material for task quality, speed, or reliability

Do not claim third-party discovery worked from policy text alone. The run needs visible evidence.
